# AGENTS.md - Руководство для AI-агентов (Antigravity)

## 1. Миссия, KPI и границы проекта (Mission & Scope)

### Цель и назначение:
**ClipShrinker** — автономная высокопроизводительная утилита на Rust для точного сжатия видеофайлов под лимиты мессенджеров и почтовых сервисов (Discord, Telegram, Slack, Mail — 1, 2, 5, 8, 10, 25 МБ) в один клик через контекстное меню проводника Windows.

### Ключевые требования и KPI:
- **Zero-Dependency (PE Overlay):** Единственный переносимый `.exe` файл (~27 МБ) содержит внутри упакованный в XZ бинарник FFmpeg. Не требует установленного Python, .NET, Node.js или FFmpeg в системном `PATH`.
- **Точность сжатия (Exact MB Targeting):** Финальный размер строго укладывается в целевой лимит с 3% запасом на накладные расходы контейнера MP4. Автоматический выбор 1-проходного или 2-проходного x264/AAC кодирования. Защита от раздувания: если файл уже меньше лимита, перекодирование отменяется.
- **Нативный Win32 GUI:** Вызов Win32 `IFileOpenDialog` и `DirectUI` без всплывающих черных окон консоли (`CREATE_NO_WINDOW = 0x08000000`).
- **Авто-локализация (i18n):** Нативная поддержка RU/EN с автоматическим определением языка системы через Win32 API `GetUserDefaultUILanguage()`.

### ⛔ Строгие ограничения (Non-Goals):
- **Запрещено** подключать тяжелые графические фреймворки или веб-рантаймы (Electron, Tauri, Qt, WPF). Используются только прямые Win32 API вызовы через крейт `windows-sys`.
- **Запрещено** превращать утилиту в нелинейный видеоредактор (NLE): добавление титров, цветокоррекция, фильтры и склейка исключены из скоупа.
- **Запрещено** поддерживать устаревшие версии Windows (XP / 7 / 8). Целевая платформа — Windows 10/11 x64.

## 2. Сборка и верификация (Build & Verification)

- **Основная сборка (компиляция Rust + упаковка PE Overlay + архив исходников):**
  ```powershell
  .\build.ps1
  ```
- **Сборка с передачей номера билда:**
  ```powershell
  .\build.ps1 -BuildNum 5
  ```
- **Прямая компиляция через Cargo:**
  ```powershell
  cargo build --release
  ```
- **Проверка версии скомпилированного стаба:**
  ```powershell
  .\target\release\clip_shrinker.exe --get-version
  ```

## 3. Архитектурные правила и инварианты

1. **Стек и компилятор:**
   - Язык: **Rust** (2021 edition), целевой таргет `x86_64-pc-windows-msvc`.
   - Зависимости: минимальный набор проверенных крейтов (`windows-sys`, `lzma-rs`).
2. **Архитектура PE Overlay:**
   - FFmpeg сжимается в `ffmpeg.xz` и дописывается в конец PE-бинарника (PE Overlay).
   - При первом запуске кодирования стаб считывает оверлей из собственного файла, распаковывает payload во временный каталог `%TEMP%\ClipShrinker` и запускает процесс с флагом `CREATE_NO_WINDOW`.
3. **Модульная структура (`src/`):**
   - `src/main.rs` — диспетчер CLI аргументов (`--pack-overlay`, `--get-version`), точка входа WinMain.
   - `src/gui.rs` — нативный интерфейс параметров (выбор размера в МБ, разрешения, пресета).
   - `src/compressor.rs` — расчет битрейта видео и аудио под лимит размера, запуск двухпроходного x264.
   - `src/overlay.rs` — чтение и распаковка PE Overlay.
   - `src/i18n.rs` — системная локализация интерфейса.
