# История изменений (Changelog)

Все заметные изменения в проекте **ClipShrinker** (ранее `video_convert`) документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), и проект следует семантическому версионированию.

## [9.0.2] — 2026-09-15

### Added
- **Официальный ребрендинг проекта в ClipShrinker**:
  - Пакет переименован в `clip_shrinker`, основное имя исполняемого файла `ClipShrinker.exe`, директория установки `%LOCALAPPDATA%\ClipShrinker`.
- **Автоматическая двуязычная локализация (RU / EN)**:
  - Внедрен модуль `src/i18n.rs` с автоопределением языка интерфейса Windows через Win32 API `GetUserDefaultUILanguage()`.
  - Русскоязычная Windows (`LANG_RUSSIAN = 0x0019`) → Русский интерфейс.
  - Любые другие локали мира → Английский интерфейс.
  - Поддержка тестового переопределения локали через переменную среды `CLIPSHRINKER_LANG=ru|en`.
  - Полная локализация всех компонентов приложения:
    - Нативный системный диалог `IFileOpenDialog` (заголовок, фильтры, метки «Целевой размер / Target size», «Масштаб / Scale», пресеты).
    - Каскадное контекстное меню Проводника Windows (корень `MUIVerb`, подпункты «до N МБ» / «up to N MB»).
    - Модальный диалог ручного ввода целевого размера `input_box.rs` («Целевой размер видео» / «Target Video Size», кнопки «ОК» / «OK», «Отмена» / «Cancel»).
    - Консольный ASCII-баннер, лог двухпроходного кодирования и итоговый отчет экономии места `compressor.rs`.
    - Диалоги проверки и онлайн-обновления FFmpeg `updater.rs`.
    - Установщик, проверка версий и деинсталлятор `installer.rs`.
- **Подготовка к публикации на GitHub**:
  - Созданы документы архитектуры и сборки: `PROJECT_GOAL.md`, `STRUCTURE.md`, `BUILD.md`.
  - Очищен `.gitignore`: исключены любые тяжелые бинарные файлы (`ffmpeg.exe`, `ffmpeg.xz`, `*.zip`, `*.exe`, `/bin`, `/archives`), репозиторий весит менее 1 МБ.
  - Полностью обновлен `README.md` в международном формате (English + русский раздел).
  - Автоматизирован процесс сборки в `pack.ps1` с созданием снимка исходного кода `archives/` и бинарника `bin/clip_shrinker_v9.0.2_win64.exe`.

## [9.0.1.5] — 2026-09-11

### Добавлено
- **Архитектура PE Overlay (обновление FFmpeg без перекомпиляции программы)**:
  - Исполняемый файл `video_convert.exe` теперь разделен на легковесную PE-заглушку (~500 КБ) и полезную нагрузку FFmpeg (~27.5 МБ в XZ), прикрепленную в PE-оверлее (за пределами физических секций исполняемого файла).
  - На конце файла размещается 48-байтный структурированный футер метаданных (`OverlayFooter`), содержащий сигнатуру `VCONV_OVERLAY_V1`, версию FFmpeg (`major.minor.patch`), номер билда ПО (`build`), размер распакованного `ffmpeg.exe` и размер сжатого оверлея.
  - Версия программы теперь определяется динамически из футера оверлея при старте процесса.
- **Кнопка «Проверить обновление FFmpeg» в диалоге открытия файла**:
  - В системный нативный диалог открытия файла (`IFileOpenDialog`) интегрирована кнопка проверки обновлений FFmpeg.
  - При нажатии выполняется тихий онлайн-запрос версии релиза с Gyan.dev (`curl.exe`). Если установлена актуальная версия — показывается информационное окно без вызова консоли.
  - Если доступна новая версия FFmpeg, запрашивается подтверждение на обновление с предпросмотром нового номера версии программы.
- **Механизм бесшовного самообновления программы (`updater.rs`)**:
  - Программа автоматически скачивает свежий релиз `ffmpeg-release-essentials.zip`, распаковывает `ffmpeg.exe` встроенным `tar.exe` Windows, сжимает его в XZ с помощью `lzma-rs` и пересобирает себя на лету через технику безопасного переименования `.old`.
  - **Автоматическое сохранение номера билда**: при обновлении FFmpeg (например, с 9.0.1 до 9.1.0) текущий номер билда ПО (например, 5) автоматически переносится в новую версию программы (версия станет `9.1.0.5`).
- **Скрипт автоматизированной сборки `pack.ps1`**:
  - Скрипт автоматизирует полный пайплайн компиляции PE-заглушки через `cargo build --release`, упаковку оверлея и создание дистрибутивного пакета `video_convert_v9.0.1.5.exe`.

### Исправлено
- **Исправление кодировки консоли (кракозябры/псевдографика в кириллице)**:
  - При выделении консоли на лету через `AllocConsole()` Windows инициализирует окно с кодовой страницей OEM (CP866), из-за чего вывод UTF-8 отображался некорректно.
  - Внедрена установка кодовых страниц ввода и вывода UTF-8: `SetConsoleCP(65001)` и `SetConsoleOutputCP(65001)`.
  - Принудительно устанавливается TrueType-шрифт `Consolas` через `SetCurrentConsoleFontEx`, гарантирующий корректное отображение русских букв на любых языковых версиях Windows.
  - Включен режим `ENABLE_VIRTUAL_TERMINAL_PROCESSING` для плавной отрисовки прогресс-бара.

## [9.0.1.4] — 2026-09-11

### Добавлено и улучшено
- **Полное устранение мелькания консоли при удалении и обычном старте (GUI-подсистема)**:
  - Приложение переведено на графическую подсистему Windows (`#![windows_subsystem = "windows"]`).
  - При запуске деинсталлятора из «Установленные приложения» Windows больше не создает консольное окно в принципе: процесс выполняется как 100% чистый GUI без единого черного кадра.
  - Добавлена защита фонового удаления временных файлов через флаг `CREATE_NO_WINDOW (0x08000000)` для процесса `cmd.exe`.
- **Отложенное открытие консоли (по требованию)**:
  - При обычном запуске двойным кликом сначала в чистом GUI отрабатывают проверка обновлений и системный диалог выбора файла с настройками.
  - При отмене диалога программа завершается бесследно, не создавая консоль.
  - Консольное окно выделяется динамически (`AllocConsole` / `AttachConsole`) только после того, как файл выбран и сжатие готово начаться.
- **Отображение полной строки команды FFmpeg**:
  - Перед началом кодирования в консоль выводится точная командная строка запуска FFmpeg (с корректным экранированием путей и всеми флагами: битрейт, фильтры, аудио, пресет).
- **Отказ от принудительных твиков оболочки Windows 11**:
  - Убран сторонний ключ `CLSID {86ca1aa0-34aa-4e8b-a509-50c905bae2a2}` и убран запрос на перезапуск Проводника. Оболочка Windows 11 остается в нетронутом штатном состоянии.
  - В реестре обновлен синтаксис AQS `AppliesTo` на официальный `System.FileExtension:=...` и добавлены прямые ассоциации расширений файлов для совместимости со всеми сторонними медиаплеерами (VLC, MPC-HC, PotPlayer).

## [9.0.1.3] — 2026-09-11

### Исправлено и улучшено
- **Устранение окна консоли при удалении из «Программы и компоненты»**:
  - При вызове деинсталляции (`--uninstall`) процесс немедленно отключает и скрывает окно консоли (`FreeConsole` + `ShowWindow(SW_HIDE)`), предотвращая появление пустого черного окна.

- **Интерактивное управление обновлением Проводника для Windows 11**:
  - При установке у пользователя теперь запрашивается, перезапустить ли Проводник прямо сейчас для отображения пункта «Сжать видео» сразу при первом правом клике, либо отложить перезапуск (в этом случае меню доступно через `Shift+F10` или после следующего входа в Windows).

## [9.0.1.2] — 2026-09-11


### Улучшено
- **Плавное обновление оболочки Windows без перезапуска Проводника (`SHChangeNotify`)**:
  - Полностью исключен принудительный перезапуск `explorer.exe` через `taskkill /f /im explorer.exe`. Больше нет моргания экрана, закрытия открытых папок и перезагрузки панели задач.
  - Внедрен официальный механизм Windows Shell API: `SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST | SHCNF_FLUSH, None, None)`.
  - Windows Проводник мгновенно сбрасывает кэш ассоциаций файлов и отображает новые пункты контекстного меню и иконку как в уже открытых окнах, так и в любых новых папках без какого-либо дискомфорта для пользователя.

## [9.0.1.1] — 2026-09-10


### Добавлено
- **Синхронизация базовой версии с кодеком FFmpeg 9.0.1 и поддержка билдов `9.0.1.XXX` (текущий: 9.0.1.1)**:
  - Базовый номер версии жестко привязан к версии используемого кодека FFmpeg (9.0.1).
  - Реализована 4-компонентная структура версий `Version { major, minor, patch, build }` (`9.0.1.XXX`), где 4-е число — номер сборки/билда для отслеживания мелких правок и обновлений.
  - Флаг `--get-version` и `--version` выводят полный номер сборки (например, `9.0.1.1`).

- **Интеллектуальный установщик и менеджер обновлений (`installer.rs`)**:
  - При запуске программы без параметров вне папки установки выполняется проверка:
    - *Если программа не установлена*: диалог `MessageBoxW` предлагает установить её в постоянную системную папку `%LOCALAPPDATA%\VideoConvert\video_convert.exe` и настроить меню ПКМ.
    - *Если программа установлена, но запущена более новая сборка*: диалог предлагает обновить установленную версию до новой.
    - *Если программа запущена уже из рабочей папки или версия не изменилась*: окно выбора видео открывается сразу без задержек.
  - Меню ПКМ теперь навсегда привязано к `%LOCALAPPDATA%\VideoConvert\video_convert.exe`, поэтому скачанный файл можно перемещать или удалять без нарушения работы меню Проводника.
- **Интеграция в «Установку и удаление программ» Windows**:
  - Регистрация в `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\VideoConvert` с отображением иконки, издателя, размера (~135 МБ) и версии.
  - Поддержка команды `--uninstall` для корректного удаления программы прямо через системные Параметры Windows.
- **Автоматический перезапуск `explorer.exe`**:
  - При установке, регистрации и удалении Проводник перезапускается автоматически, гарантируя немедленное появление пунктов ПКМ и фирменной иконки.
- **Динамическое поле ввода целевого размера в том же окне открытия файла**:
  - Через COM-интерфейсы `IFileDialogEvents` и `IFileDialogControlEvents` реализован слушатель событий изменения выбора элементов.
  - Поле ввода размера `Укажите размер (МБ): [ 10 ]` активируется и отображается прямо в том же окне выбора файла **только при выборе пункта «Другой размер...»**.
  - При выборе любого стандартного пресета (1, 2, 3, 5, 7, 10, 15 МБ) диалог остаётся чистым (поле ввода скрыто/неактивно), а сжатие стартует сразу после выбора файла.
  - Убрано слово «вручную»: пункт выпадающего списка переименован в `Другой размер...`.
- **Контекстное меню ПКМ**:
  - 8-й пункт каскадного подменю переименован в `Другой размер...` (открывает компактное модальное окно `InputBox` с быстрым подтверждением по Enter).
- **Выбор масштаба картинки (25%..100% с шагом 5%)**:
  - В нижнюю панель диалога встроен выпадающий контрол `Масштаб картинки:` со значениями от 100% до 25% (шаг 5%).
  - При выборе масштаба менее 100% разрешение видео пропорционально масштабируется, гарантируя чётные размеры сторон для H.264 и значительно уменьшая размер и время кодирования.
  - Поддерживается CLI-флаг `--scale <%>` (например, `--scale 75` или `--scale 50`).
- **Прямая поддержка контекстного меню для Windows 11**:
  - При регистрации (`--register`) автоматически настраивается безопасный ключ пользователя `HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32`.
  - Пункт «Сжать видео» отображается в Windows 11 **сразу при правом клике мыши**, без необходимости нажимать «Показать дополнительные параметры» (`Shift+F10`).
  - При вызове `--unregister` ключ удаляется, восстанавливая исходный вид Windows 11.
- **Очистка названий в списке размеров**:
  - Убрана фраза «по умолчанию» из элемента списка: отображается лаконичное `10 МБ` (остаётся предвыбранным по умолчанию).
  - Заголовок окна диалога очищен до `«Выберите видео для сжатия»`.

### Исправлено
- **Устранено дублирование пунктов подменю ПКМ**:
  - Удалено внешнее хранилище `VideoConvert.Menu`, из-за которого Проводник считывал пункты дважды (14 строк вместо 7).
  - Теперь используется единое чистое каноническое дерево `shell\01..08` в ключе `CompressVideo`.

## [9.0.1] — 2026-09-10

### Добавлено
- **Встроенный FFmpeg 9.0.1 Essentials**:
  - Полный официальный релиз FFmpeg упакован с помощью LZMA-сжатия прямо в исполняемый файл.
  - Автоматическое быстрое извлечение в `%LOCALAPPDATA%\VideoConvert\bin\ffmpeg_9.0.1.exe` при первом запуске (повторные запуски происходят мгновенно).
- **Каскадное контекстное меню Проводника (ПКМ)**:
  - Меню **«Сжать видео»** с подпунктами выбора целевого размера:
    - `до 1 МБ`
    - `до 2 МБ`
    - `до 3 МБ`
    - `до 5 МБ`
    - `до 7 МБ`
    - `до 10 МБ`
    - `до 15 МБ`
  - Поддерживаются форматы `.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.wmv`, `.flv`, `.3gp`, `.ts`, `.m4v`.
  - Корректная регистрация через `ExtendedSubCommandsKey` и `SubCommands` в ветке `HKEY_CURRENT_USER` — не требует прав администратора.
- **Интеллектуальный анализ входного видео**:
  - **Защита от раздувания (Output <= Input)**: если исходный файл уже меньше или равен целевому размеру (например, файл 3 МБ при выборе «до 10 МБ»), программа выводит предупреждение и отменяет операцию, предотвращая ухудшение качества и увеличение веса файла.
  - **Автоматический выбор режима кодирования (1-pass / 2-pass)**:
    - *1-проходный режим (Single-Pass)*: автоматически активируется для коротких видео ($\le 12$ сек) или при избыточном битрейте ($\ge 5000$ кбит/с), ускоряя процесс в 2 раза.
    - *2-проходный режим (Two-Pass)*: автоматически активируется при строгом ограничении битрейта для более длинных видео, обеспечивая максимальное качество и точность размера.
  - **Адаптивное масштабирование разрешения (Smart Downscaling)**:
    - $\ge 1400$ кбит/с $\rightarrow$ до 1080p
    - $650 - 1400$ кбит/с $\rightarrow$ до 720p
    - $300 - 650$ кбит/с $\rightarrow$ до 480p
    - $< 300$ кбит/с $\rightarrow$ до 360p
- **Ненавязчивый запуск с размером по умолчанию 10 МБ**:
  - При запуске программы без аргументов окно выбора видеофайла открывается **мгновенно**.
  - После выбора файла отображается размер по умолчанию (**10 МБ**) и 3-секундный таймер автозапуска: можно нажать Enter для мгновенного старта, ничего не нажимать (автостарт через 3 сек), либо ввести другой размер в МБ.
- **Вшитая иконка приложения**:
  - Создана многослойная векторно-растровая иконка высокого разрешения `app_icon.ico` (от 16x16 до 256x256).
  - Иконка вшита через Windows Resource Compiler в PE-заголовок файла и отображается в Проводнике и контекстном меню.
- **Универсальная совместимость видео**:
  - Кодеки **H.264 (High Profile, `yuv420p`) + AAC (Stereo)** в контейнере **MP4**.
  - Флаг `-movflags +faststart` переносит заголовок `moov` в начало файла для мгновенного потокового воспроизведения в Telegram, Discord и браузерах.
- **Флаги командной строки**:
  - `--register` / `-r`: добавление каскадного меню в ПКМ.
  - `--unregister` / `-u`: удаление пунктов меню из реестра.
  - `--target <N>` / `-t <N>`: указание целевого размера в МБ.
  - `--no-pause` / `-y`: пакетный запуск без ожидания нажатия Enter.

### Исправлено
- **Отображение и кликабельность подпунктов ПКМ**:
  - Удалено строковое значение по умолчанию `(Default)` у родительского ключа `CompressVideo`, которое приводило к интерпретации меню как обычной одиночной команды без подменю.
  - Реализован механизм `ExtendedSubCommandsKey = "VideoConvert.Menu"`, обеспечивающий надёжное раскрытие каскадного списка подкоманд в Проводнике Windows 10/11.
