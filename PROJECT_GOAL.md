# PROJECT_GOAL: ClipShrinker

## 1. Цель и миссия (Mission Statement)
**ClipShrinker** — сверхбыстрая, автономная Windows-утилита для точного сжатия видеороликов под строгие ограничения размера файлов (1, 2, 5, 8, 10, 25 МБ и др.) для отправки в Discord, Telegram, почте, Slack и веб-формах в один клик.

Проект решает фундаментальную проблему: пользователю нужно быстро отправить видеоролик в мессенджер с лимитом размера (например, 10 МБ в Telegram или 8/25/50 МБ в Discord), не разбираясь в битрейтах, двухпроходном кодировании и аргументах командной строки.

---

## 2. Ключевые требования и KPI (Key Performance Indicators)

1. **Автономность (Zero Dependencies):**
   - Единый исполняемый файл `.exe` без требований к установке Python, .NET, сторонних кодеков или ручной настройки `PATH` для FFmpeg.
   - FFmpeg интегрирован прямо в бинарник через архитектуру **PE Overlay** с XZ-компрессией (размер файла ~27 МБ вместо 130+ МБ).
2. **Точность размера (Exact MB Targeting):**
   - Итоговый размер файла должен строго укладываться в заданный лимит (с запасом безопасности 3% на контейнер MP4/мультиплексирование).
   - Автоматический выбор между 1-проходным (при высоком битрейте) и 2-проходным x264/AAC кодированием (при жестких лимитах).
   - Защита от раздувания: если входной файл уже меньше или равен целевому размеру, перекодирование не производится.
3. **Бесшовный UX и нативный интерфейс:**
   - Каскадное контекстное меню Проводника Windows (ПКМ) для любого видеофайла.
   - Нативный диалог `IFileOpenDialog` с выпадающими списками целевого размера и масштаба, идеально выровненный по базовой линии шрифта DirectUI.
   - Полное отсутствие мерцания консольных окон при вызове GUI (`CREATE_NO_WINDOW = 0x08000000`).
4. **Интернационализация (i18n):**
   - Автоматическое определение языка интерфейса Windows (`GetUserDefaultUILanguage()`):
     - Русскоязычная Windows (`0x0019`) → Русский интерфейс.
     - Любые другие локали мира → Английский интерфейс.
5. **Безопасное самообновление FFmpeg:**
   - Проверка и загрузка свежих билдов FFmpeg с gyan.dev без перекомпиляции основного приложения (перезапись PE Overlay).

## 3. Границы проекта (Scope & Non-Goals)

### Входит в Scope:
- Поддержка форматов MP4, MOV, MKV, AVI, WEBM, WMV, FLV, 3GP, TS, M4V.
- Пресеты размеров: 1, 2, 3, 5, 7, 10, 15, 25, 50, 100 МБ + произвольный ввод.
- Масштабирование разрешения (100%..25% с шагом 5% и кратностью чётным пикселям 2x2).
- Интеграция в системное меню Windows «Установка и удаление программ».
- Сборка легковесного open-source репозитория для публикации на GitHub.

### Non-Goals (Исключено):
- Редактирование таймлайна, эффекты, цветокоррекция (для этого есть NLE видеоредакторы).
- Поддержка устаревших ОС Windows 7/XP (требуется Windows 10/11 x64).
- Сторонние фреймворки с тяжелыми рантаймами (Electron, Python/Tkinter, WPF).
